# ОБЪЁМ — сайт-портфолио архитектурного бюро

Статический одностраничник: чистый HTML, CSS и JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`.

## Что внутри

```
index.html            разметка страницы
assets/css/style.css  стили, токены, адаптив
assets/js/app.js      поведение: меню, появление блоков, счётчики, языки
assets/js/i18n.js     словари переводов (RU, EN, DE, FR, ES)
assets/img/           фотографии
docs/STRUCTURE.md     разбор референсов и структура
refs/                 исходные референсы
```

## Языки

Пять языков: русский, английский, немецкий, французский, испанский.
Переключатель — в шапке справа, на телефоне — внизу бургер-меню.
Язык определяется по браузеру и запоминается в `localStorage`.

Ключ словаря — сама русская строка, поэтому чтобы поправить перевод,
достаточно найти русскую фразу в `assets/js/i18n.js`. Новый текст на странице
достаточно добавить в разметку и дописать строку в каждый словарь.

## Как выложить

**GitHub Pages** — Settings → Pages → Source: ветка и папка `/ (root)`.
Через минуту сайт открывается по адресу
`https://bonifirmaarm-design.github.io/house/`.

Любой другой хостинг — просто залить папку целиком, сервер не нужен.

## Проверено

- Chromium, десктоп 1440 и телефон 390 — горизонтальной прокрутки нет ни на одном из пяти языков.
- Клавиатурная навигация, видимый фокус, `prefers-reduced-motion`.
- Фотографии — WebP, здание на первом экране — PNG с прозрачностью.
